# 🏠 Aadhi Interiors

Aadhi Interiors is a Vadalur-based interior design and execution studio offering complete home and commercial interior solutions — modular kitchens, wardrobes, false ceilings, furniture, painting, and turnkey renovation.  
This repository contains the source code for the official website hosted on **GitHub Pages**.

---

## ✨ Features
- Responsive landing page with modern UI
- Google Maps integration for location
- Booking form with date selection
- Ratings display (no reviews)
- Image gallery showcasing interior projects
- Mobile-friendly layout
